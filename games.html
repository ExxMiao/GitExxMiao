开发者：如何接入一个新游戏
  1. 在 games/ 下新建文件夹，例如 games/2048/，放入 index.html、game.css、game.js，页面直接引用 ../../assets/css/base.css 即可继承全站风格。
  2. 打开 assets/js/games-registry.js，在 window.GAME_REGISTRY 数组里追加一条配置（id / name / path / tags / icon 等）。
  3. 刷新本页，新游戏会自动出现在卡片列表里；无需修改本页任何代码。
